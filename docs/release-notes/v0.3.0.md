Everything from v0.2.0 still works the same way. This adds a way to ask the
library to refresh itself from Civitai on demand, rather than only from
`mm enrich` on the command line.

## Refresh from origin

Every model panel now has a **Refresh from origin** button: one lookup by
content hash, merged into what is already known. Nothing about how a merge is
decided has changed — a value you typed still wins, a value the origin
contradicts is raised as a suggestion instead of silently overwritten, a blank
field takes the best answer available, and a thumbnail you chose still cannot
be displaced by a fetched one. This only adds a way to trigger it without
leaving the browser.

Two more places do the same lookup at scale:

- The **library toolbar** gets a button scoped to whatever the current filters
  select — not just the page loaded, the whole matching set — so "refresh
  everything missing a base model" is one click after applying that filter.
- **Settings** has a whole-library sweep with progress and a Stop button.
  Stopping keeps everything already fetched; running again continues rather
  than starting over, the same as `mm enrich` always has.

A model whose hash is still provisional (bound by a sampled probe rather than a
full read) is skipped rather than queried, same as the CLI — querying an origin
with an unconfirmed hash could archive someone else's metadata under this file.
Run `mm verify --provisional` first if you hit that.

## Upgrading

No schema changes and nothing to run by hand.
