A one-bug release: the per-type download folder fields in Settings could not
be typed into.

## Fixed

**Every character typed into a download-folder field threw the caret out of
it**, so setting a folder name took one click per letter.

The field saved on every keystroke. That save sets a busy flag for the
duration of the request, the busy flag disabled the input, and a browser
blurs an element the moment it becomes disabled — so each character disabled
the field, dropped focus, and re-enabled it. It also sent one request per
character.

The value is now held locally and saved when you leave the field, which is
what every other text setting on that panel already did; this one was the
exception. Enter saves as well. The fields also no longer grey out while a
save is in flight, so a save that overlaps with typing cannot interrupt it —
matching the rest of the panel, where only buttons are disabled during a
save.

## Upgrading

No schema changes and nothing to run by hand.
