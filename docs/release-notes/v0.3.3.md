A one-bug release: Browse's thumbnails, all of them, were broken.

## Fixed

**Every thumbnail in Browse showed as broken.** Civitai's image host now
301-redirects to a different CDN host than the one this daemon's allowlist
recognized, so the image proxy refused it — since a broken `<img>` just
renders empty, this failed silently rather than with an obvious error.

The underlying fix goes a step further than patching in the one new
hostname: the image proxy's allowlist matched by exact hostname, while the
download allowlist next to it already matched by domain for the same
reason ("providers shard CDN traffic across subdomains this daemon can't
enumerate in advance"). The two are now one shared allowlist, matched by
domain, so the next time a provider moves its CDN this does not need
another release to keep working.

## Upgrading

No schema changes and nothing to run by hand.
