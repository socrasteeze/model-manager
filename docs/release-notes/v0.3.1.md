A bugfix release for v0.3.0's "refresh from origin" feature. Nothing about how
values are merged has changed — this only fixes how faithfully a sweep reports
what it actually did.

## Fixed

**A stopped or rate-limited sweep reported itself 100% done.** `Enrich` always
called its final progress callback with the full eligible count, regardless of
how far the loop actually got before breaking. Stopping a sweep, or having the
origin rate-limit it, now reports the true number of models reached.

**A rate-limited sweep was indistinguishable from a finished one.** The daemon
now tracks whether the origin rejected a request during the run and surfaces
it — the sweep still ends in the same state (nothing failed, nothing was
cancelled), but the UI now tells you to run it again to be sure everything was
covered.

**Live counts stayed at zero until a sweep finished.** Matched, missing,
images and errors now update as the sweep runs rather than only appearing in
the final summary.

**Refreshing one model scanned the whole library first.** The single-model
"Refresh from origin" button now looks the model up directly by hash instead
of scanning and sorting every eligible model to find it — the same lookup a
20,000-model library used to cost tens of milliseconds now completes in
sub-millisecond time.

## Upgrading

No schema changes and nothing to run by hand.
